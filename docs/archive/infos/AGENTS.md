# AGENTS.md — Tactical Summoners (read this first, any AI agent)

Applies to ChatGPT/Codex, Claude, Cursor, Copilot, Gemini and humans. The repo (Git) is the single source of truth. Chat memory is NOT.

## LITE MODE (default for chat AIs, saves usage)
User gives you only `CONTEXT_LITE.md` (~10 KB, built by `python tools/sync/ts_sync.py lite --spec NAME`). Do not ask for the full bundle or other docs; if you truly need one, name the exact file. One task per session. End with a log entry + changed lines of CURRENT_STATE only (no full-file patches).

## Start of every session (full mode, only if you have shell/repo access)
1. `python tools/sync/ts_sync.py start` — prints pack version, state hash, open claims and Git status.
2. Read, in order: `docs/ai-context/CURRENT_STATE.md`, `TASK_BOARD.md`, last 3 entries of `HANDOFF_LOG.md`, `DECISIONS.md`, then the spec relevant to your task.
3. No shell access (plain chat)? Ask the user for `CONTEXT_BUNDLE.md` (built by `ts_sync.py bundle`) and confirm its `STATE_HASH`.
4. Claim your task: `python tools/sync/ts_sync.py claim T-xxx --agent "<name>"`. Do not touch tasks claimed by another agent.

## During work
- **No-hands Godot (D-019):** the owner will not touch the Godot editor. You implement everything via scripts (GDScript, @tool EditorScripts, `godot --headless`, PowerShell on Windows), including animations from sprite sheets (SpriteFrames/AnimationPlayer generated by script) and scene wiring. Deliver script + one run command + expected result. Never say "open the editor and click".
- The real Godot project may exist only on the owner's machine. If you have not seen it, ask for the repo or a ZIP before writing code; never assume the project is empty.
- Inspect the real Godot project before editing. Preserve existing work. Commit/checkpoint first.
- Script-first: generators, `@tool` EditorScripts, CLI. Manual editor steps only when unavoidable.
- Never contradict an approved decision in `DECISIONS.md`. If you think one is wrong, propose a new D-xxx entry; do not silently deviate.
- No pause/time-slow. Direct orders are never randomly refused. Heroes never re-roll on load. Procedural worlds are deferred.
- Never claim something is implemented/tested unless you ran it. Record the command and result.
- Never write secrets (keys, tokens, `.env`) into any file.

## End of every session (mandatory)
1. `python tools/sync/ts_sync.py log --agent "<name>" --did "..." --verified "..." --next "..."`
2. Update `CURRENT_STATE.md`, `ROADMAP.md` checkboxes (only if verified) and `CHANGELOG.md`.
3. `python tools/sync/ts_sync.py release T-xxx --status done|blocked|handoff`
4. `python tools/sync/ts_sync.py check` must pass, then commit and push.
5. Tell the user the new `STATE_HASH` so the next agent can confirm it is up to date.

If you cannot run scripts (plain chat), output a `SESSION_END_PATCH` block: full replacement text for each changed file plus a HANDOFF_LOG entry, so the user can paste it into the repo.

## Authority when documents disagree
`DECISIONS.md` > spec files (`CONTROL_…`, `SUMMONS_…`, `COMBAT_…`) > `PROJECT_BIBLE.md` > `ROADMAP.md` > checklist > chat messages. Report the conflict in `HANDOFF_LOG.md` and fix the lower-authority file.
